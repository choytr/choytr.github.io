## About

This portfolio was built with the [LightSpeed Jekyll theme](https://github.com/tajacks/lightspeed).

## Installation

To set it up, install [Ruby](https://www.ruby-lang.org/en/documentation/installation/) and [Jekyll](https://jekyllrb.com/docs/installation/) (make sure you install [bundler](https://bundler.io/) too).

Then run:

```
bundle exec jekyll serve
```

and view the site at `localhost:4000`.
